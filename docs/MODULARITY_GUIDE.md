# Modularity & Swapping Guide: Zero-Rewrite Vendor Portability

Every layer of the Contractor Front Office Automation architecture is intentionally decoupled. Replacing any vendor requires **only updating environment credentials and one field-mapping node in n8n**, with zero rewrites of core orchestration or state logic.

---

## 1. Swapping Airtable for a Different CRM (e.g. ServiceTitan, HubSpot, Jobber)

The CRM layer expects a standardized lead object:
`{ LeadID, Name, Phone, Location, JobType, Urgency, Description, Status, BookedSlot, NextAction }`.

### To Swap to ServiceTitan:
1. **n8n Change**:
   - In **Workflow A** and **Workflow B**, replace the HTTP Request node pointing to Airtable with the native **ServiceTitan** node (or HTTP Request to `https://api.servicetitan.io/crm/v2/tenant/{tenant}/jobs`).
   - Map fields:
     - `Name` &rarr; `customer.name`
     - `Phone` &rarr; `customer.phoneSettings.phoneNumber`
     - `Location` &rarr; `location.address`
     - `JobType` &rarr; `jobTypeId`
     - `Description` &rarr; `summary`
2. **Environment Variables**:
   - Add `SERVICETITAN_CLIENT_ID`, `SERVICETITAN_CLIENT_SECRET`, `SERVICETITAN_TENANT_ID` to `.env`.
   - Remove `AIRTABLE_ACCESS_TOKEN` and `AIRTABLE_BASE_ID`.

### To Swap to HubSpot:
1. Replace Airtable node with n8n's native **HubSpot** node.
2. Action: Create / Update Deal or Contact with matching standard properties.

## 2. Swapping Cal.com for a Different Scheduler (e.g. Calendly, Google Calendar)

The scheduling layer requires two capabilities:
1. Query available slots given a time window.
2. Book an event with customer details.

### To Swap to Calendly:
1. **n8n Change**:
   - In **Workflow B**, replace the Cal.com HTTP Request node with Calendly's API:
     - Availability: `GET https://api.calendly.com/event_type_available_times`
     - Booking: Calendly utilizes user-driven links; the workflow sends `https://calendly.com/{user}/{event_type}?name={name}&email={email}` via SMS.
2. **Environment Variables**:
   - Replace `CALCOM_API_KEY` and `CALCOM_EVENT_TYPE_ID` with `CALENDLY_API_KEY` and `CALENDLY_EVENT_UUID`.

### To Swap to Google Calendar:
1. Use n8n's built-in **Google Calendar** node.
2. Method: **Availability: Check Free/Busy** &rarr; **Event: Create**.

## 3. Swapping Vapi for Retell AI (or Bland AI)

Both Vapi and Retell capture phone audio and emit structured end-of-call webhooks.

### To Swap from Vapi to Retell AI:
1. **Retell Dashboard Setup**:
   - Go to Retell AI dashboard and create an agent.
   - Set LLM to Custom LLM or paste the prompt from [config/prompt_templates.js](file:///d:/Softskills%20Engineering/Agent/config/prompt_templates.js).
   - Set the Retell webhook URL to: `https://<your-domain>/api/webhooks/vapi` (or n8n Webhook node).
2. **n8n / Server Webhook Adapter**:
   - Retell payloads provide `call_analysis.custom_analysis_data` or `transcript`.
   - The ingestion endpoint automatically detects Retell payloads (`call.call_type` vs `call.endedReason`).
3. **Environment Variables**:
   - In `.env`, populate `RETELL_API_KEY` and update `VAPI_PHONE_NUMBER` with your Retell phone number.

## 4. Swapping Twilio for a Different SMS/Email Provider (e.g. Postmark, SendGrid, AWS SNS)

Notification routing is decoupled inside **Workflow C** and `src/services/notifications.js`.

### To Swap to Postmark / SendGrid (Email Primary):
1. **Change Configuration**:
   - In `.env`, set:
     ```env
     CONTRACTOR_NOTIFY_CHANNEL=email
     ```
2. **n8n Change**:
   - In **Workflow C**, replace the Twilio node with the native **SendGrid** or **Postmark** node.
   - The body string generated by the template is passed directly to the `content` field.

### To Swap to AWS SNS (SMS):
1. In **Workflow C**, replace the Twilio HTTP node with the **AWS SNS** node (`Action: Publish Message`).
2. Map `phoneNumber = lead.Phone` and `message = templateOutput`.
